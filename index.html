アプリについて

のりかえNavi は NAVITIME 風の乗換案内デモPWAです。
ブラウザのメニューから「ホーム画面に追加」すると、アプリのように起動できます。

収録サンプル路線(東京エリア):
JR山手線 / JR中央線快速 / JR横浜線 / JR東海道線 / 小田急小田原線 / 東急東横線

収録サンプル路線(大阪・京阪神エリア):
JR大阪環状線 / JR京都・神戸線 / JR東西線 / JRゆめ咲線 / 阪急(神戸・京都・宝塚線) / 阪神本線 / 京阪本線 / 近鉄奈良線 / 南海(本線・高野線) / Osaka Metro(御堂筋・谷町・中央・四つ橋・堺筋線)

※「大阪」→梅田、「難波」→なんば、「USJ」→ユニバーサルシティ など別名でも検索できます。エリアをまたぐ検索(東京↔大阪)はできません。

※出発地・目的地に「現在地」を選ぶとGPSから最寄り駅まで徒歩でつなぎます(位置情報の許可とHTTPS接続が必要)。近接駅(大阪天満宮↔南森町、梅田↔北新地など)は徒歩連絡で自動的に乗り換えます。

時刻・運賃・遅延情報はすべてデモ用データであり、実際の運行情報ではありません。
