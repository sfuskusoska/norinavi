# のりかえNavi

NAVITIME風の乗換案内デモPWAです。スマホのブラウザで開き、「ホーム画面に追加」するとアプリのように使えます。

## 機能

- **乗換ルート検索** — 出発地・目的地・日時(出発/到着)を指定して複数候補を表示(早・安・楽バッジ、混雑度、きっぷ/IC運賃)
- **フリーパス選択** — 青春18きっぷ等を選ぶと、パスが使えるルートを優先表示し、対象区間の運賃を¥0で計算
- **遅延情報の登録(拡張機能)** — 路線ごとに遅延や運転見合わせを登録すると、検索結果の所要時間に反映。運転見合わせ路線は検索から除外
- **自転車・徒歩モード** — 距離・所要時間・消費カロリーの概算を表示
- **経由地の複数指定** — 最大8件の経由地を追加可能
- **地図表示** — OpenStreetMap(Leaflet)で経路を描画
- **Googleマップ連携** — 検索したルートをGoogleマップ(経由地付き)で開ける
- **PWA対応** — オフラインキャッシュ、ホーム画面への追加

## 収録サンプル路線

JR山手線 / JR中央線快速 / JR横浜線 / JR東海道線 / 小田急小田原線 / 東急東横線(約60駅)

## ローカルでの起動

```
python -m http.server 8765
```

を本フォルダで実行し、ブラウザで `http://localhost:8765` を開きます。

## 注意

時刻・運賃・遅延情報・距離はすべてデモ用サンプルデータによる概算であり、実際の運行情報ではありません。
